Plataforma

Cambia los comandos del final. El archivo de variables es el mismo.

Base de datos (MongoDB Atlas)

Atlas → Database → Connect → Drivers. Acordate de reemplazar <password> por la clave real y de agregar /biosoft al final.

Broker MQTT

El mismo al que publica la placa (esp32/include/secrets.h). Conviene crear una credencial aparte para el backend.

Sesiones y primer usuario

El usuario y la contraseña de aca son los que vas a usar para entrar al dashboard: los elegis vos ahora, no salen de Atlas ni del broker. El servidor crea esa cuenta la primera vez que arranca, y solo si la base todavia no tiene ningun usuario. Cambiala apenas entres, porque queda escrita en las variables de entorno de la plataforma.

Se genera en el navegador con crypto.getRandomValues.
